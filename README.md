# 无障碍验证降级

无障碍通道本意是给读屏用户放行，结果只要声明读屏就能跳过验证，撞库脚本全都这么声明：验证码降级必须经过独立核验并按账号限次留痕，批量校验时每个请求单独判定。

## 契约

- 降级通道必须经过独立核验。
- 降级必须限次并留痕。
- 降级不能成为默认路径。
- 降级用户的后续请求必须重点监控。
- 降级策略必须由服务端决定。
- 批量校验各请求独立。

## 不变量

- 声明式降级永远无法免验证通过。
- 同一账号降级次数有上限。

## 测试

在仓库根目录执行 python -m pytest tests -q 查看行为测试结果。
